Calightra RTL Simulator Caliptra 2.1 compat Stripped RTL · Verilator WASM

Calightra’s modified, area-stripped Caliptra 2.1 SystemVerilog RTL (caliptra_top: VeeR EL2 RISC-V core, Adams Bridge ML-DSA-87 & ML-KEM-1024, ECC P-384, SHA2/SHA3, AES-GCM, Key/PCR Vaults, and AXI4-Lite Mailbox — with side-channel masking/blinding countermeasures, SRAM ECC, VeeR PMP/JTAG debug, and SVA assertions stripped out for a ~20× smaller model) compiled with Verilator to WebAssembly and executing unmodified upstream Caliptra 2.1 ROM & Runtime firmware by default (with an optional caliptra-sw Fake ROM test mode that skips KATs and IDevID/LDevID DICE flows for faster interactive mailbox testing).
